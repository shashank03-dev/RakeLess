# 60-second demo script

| Time | Screen | Say |
|---|---|---|
| 0–7 s | Landing page, the real photo | "I was about to rake everything. Some of that work may be unnecessary." |
| 7–18 s | Hero map, the **● REC** label | "This is a saved, real Gemma 4 run. The colors are suggestions and review flags, not surveyed boundaries." |
| 18–30 s | Click C2, then C3 | "Leave this patch for now; here's what the model saw and the source. But still clear this lane." |
| 30–40 s | Workbench → recorded example → C1 → set Surface to **Lawn** | "The model called this a bed, but there's grass by the shed. I correct it. The suggestion changes, and no photo is sent again." |
| 40–50 s | Upload a new photo → live stages + elapsed timer | Show the real elapsed time. Do not cut the wait without showing the timer. |
| 50–60 s | Print plan (and yard sign page) | "Less leaf clearing, with a reason for every skipped patch." |

Rules for the recording:
- The recorded example must stay labeled "RECORDED RUN". Never present it as live.
- If a live run abstains (everything in review), show that honestly. Don't re-roll until it looks good.
- The live run uses the hosted Gemini API. Don't film it as an "offline" run.
